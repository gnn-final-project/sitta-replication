# sitta-replication

This repository contains the implementation and replication materials for the project "SITTA: Spatially Invariant Transfer and Transformation of Arbitrary Images." The goal is to reproduce the results presented in the original study and provide resources for further exploration.

## Project Structure

The repository is organized as follows:

- `ArtStyle/`: Contains code and data related to style transfer experiments.
- `CycleGAN/`: Implementation of CycleGAN-based image transformations.
- `FUNIT/`: Few-shot unsupervised image-to-image translation methods.
- `SITTA/`: Core implementation of the SITTA model.
- `SinGAN/`: Single-image GAN experiments and results.
- `TuiGAN/`: Implementation of TuiGAN for image translation tasks.
- `plant_pathology_classification/`: Materials related to plant pathology image classification.

## Getting Started

To set up the environment and run the replication experiments:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/gnn-final-project/sitta-replication.git
   cd sitta-replication
2. **Install required dependencies:** 
   ```bash
   pip install -r requirements.txt
3. **Run experiments:** Navigate to the directory of the experiment you wish to replicate and run Jypyter notebooks.
